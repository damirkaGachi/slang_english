# Переводчик с молодёжного: шпаргалка для взрослых

Сайт с карточками для изучения молодёжного сленга. Каждая карточка — одно слово. Кликаешь на колоду, берёшь карточку, переворачиваешь и читаешь определение, а по кнопке «История» открываешь историческую справку: откуда слово появилось и от кого пришло. Потом карточку можно положить в одну из двух стопок: «Знаю» или «Ещё повторить».

**Ссылка на сайт:** https://damirkagachi.github.io/slang_english/

## Как пользоваться

1. Нажать «Начать изучение».
2. Нажать на колоду, чтобы взять карточку.
3. Нажать на карточку, чтобы перевернуть её и увидеть определение.
4. Нажать «История», чтобы справа появилась историческая справка.
5. Положить карточку в стопку «Знаю» или «Ещё повторить». Из любой стопки её можно взять обратно и переложить.
6. Когда колода закончится, можно повторить только слова из стопки «Ещё повторить» или начать заново.

## Как добавить или изменить слова

Все слова лежат в одном месте — в файле `index.html`, в блоке между комментариями `СЮДА ВПИСЫВАЕМ СЛОВА` и `ДАЛЬШЕ ТРОГАТЬ НЕ НУЖНО`. Одно слово занимает одну строку:

```
{word:"Имхо",def:"Определение слова.",hist:"Историческая справка."},
```

- `word` — слово на карточке;
- `def` — определение простыми словами;
- `hist` — историческая справка.

Правила:

- текст пишется внутри кавычек;
- внутри текста нельзя использовать обычные двойные кавычки `"`, вместо них нужны «ёлочки»;
- после каждой строки ставится запятая, кроме самой последней в списке.

## Как обновить сайт

1. Открыть `index.html` в репозитории на GitHub.
2. Нажать на значок карандаша и внести правки.
3. Нажать **Commit changes**.
4. Через 1–2 минуты сайт обновится по той же ссылке.

## Из чего состоит проект

Весь сайт — один файл `index.html`: без сборки, без сервера и без внешних библиотек. Он публикуется через GitHub Pages (ветка `main`, папка `/ (root)`).

## Цвета и оформление

- фон — градиент от тёмно-синего через фиолетовый к розовому;
- карточки — оранжевые;
- историческая справка — серая секция справа от карточки.
